## 已核对

- 实施起点为插件 `b516ceb`、SDK `c91b806`、父仓 `af98ce69`；没有重置工作区。未提交的迁移计划已保留。
- 开发与软件测试使用已有 devbox；目标机器 `nzh-mbpm1` 已通过 SSH 主机名与架构核对。尚未将历史设备身份视作当前验收。

## 验证与审查

- SDK 核心已从旧页面入口抽出，独立 `serve`、认证发现、实例概要和显式服务退出已实现；服务启动不自动连接设备。
- SDK 独立服务阶段已本地提交 `33301c8`；配套插件已重新打包并更新至两个官方验收 profile，等待完整安装旅程。
- USB/CAN 物理通路锁已接入默认直连与服务打开点；开发容器中的锁、生命周期和连接相关测试通过。独立审查发现的 SLCAN 身份变化与 USB 退出清理问题已修复并通过限定复审。
- 可轮询查询的两项取消/Stop 通路问题已按真实 worker 边界修复并通过限定复审，SDK 前置片已本地提交 `72f0b11`；控制能力尚未在新服务开放。
- 目标机器 USB、受管 CAN、ODrive 只读预检成功。历史已恢复低速电机与停止的范围，当前仍未执行迁移版运动验收；模拟传感器的遥测不作为机械效果证明。
- 官方 DSH 实际安装后的离线按钮调用和服务设置保存通过；校验错误重复呈现已修复并在界面复验。错误工具版本的新提示尚待最终包验证。
