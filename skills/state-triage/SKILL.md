# 状态分诊

用于解释工作台中当前目标已经得到的官方输出，不创建额外工作流。

1. 用户限定只看当前选择时，只调用 `fieldkit_context()`；它只提供当前目标、内存 `lastResult` 和静态命令目录。没有目标就说明缺口。
2. 用户请求新的只读状态时，使用 `fieldkit_command(...)` 调用用户指定的官方只读命令；不猜测其它目标，也不追加未被请求的命令。
3. 将 HTTP 状态、`bodyText`、错误、unknown、目标和报告路径分为“官方结果”“判断”“未决项”。

unknown 是本次命令反馈，不能被解释为后续命令的插件锁。不要展示 token、真实主机路径或未公开的服务数据。
