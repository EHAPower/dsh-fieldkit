# 状态分诊

用于把一次公开 SDK 的只读诊断整理为可审阅的现场分诊报告。只可使用 `fieldkit_devices` 和 `fieldkit_diagnose_usb`；不得读取仓库内容、选择未获确认的设备，或调用运动、停止、复位、保存、清错和维护操作。

1. 若操作者尚未明确给出完整 USB 序列号，先运行 `fieldkit_devices` 并请其在图形界面中选择一台。候选列表不能代替选择，也不能自动选择第一项。
2. 仅对已确认的完整序列号调用 `fieldkit_diagnose_usb({ serial })`。
3. 用工具保存的 Markdown / JSON 路径作为报告证据，逐项呈现身份、状态、测量、诊断、Startup 与 user configuration 的可用性或错误。
4. 检查各快照的 UID 与 `run_nonce`；不一致时，报告“运行实例不一致”，不要合并解释。离散读取没有共同原子时刻，也不代表连续监控。

报告分为“证据”“判断”“未决项”。证据只复述工具结果和路径；判断说明哪些公开可观察结果值得人工跟进；未决项列出缺失、失败、实例不一致或需要现场负责人确认的条件。不要把一次状态或诊断快照推断为通信持续正常、内部链路正常、输出获准、设备执行、机构运动或全局安全。有效分诊表示本次证据足够支持所写判断；不完整分诊表示不能得出该判断。
