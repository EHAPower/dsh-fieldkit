# 配置记录审查

用于检查操作者在 Harness 图形界面中明确提供的完整配置记录。只可使用 `fieldkit_check_configuration({ record })`；不要从设备、源码仓库或其他本地资料自动取得记录，也不要执行保存、复位、维护、清错或运动。

1. 检查用户在界面中明确提供的完整配置记录；已经给出的输入不需再次确认。输入不完整或对象不明确时，请其补充，不能从设备或任意文件自行寻找记录。
2. 优先将原始 JSON 文本作为 `record` 调用 `fieldkit_check_configuration`，不要先转换数值再重新生成配置。该检查通过官方 `eha-tool` 执行静态验证，不连接或写入设备。
3. 报告输入范围、验证结果、字段/跨字段错误或警告，以及工具返回的原始诊断。不要展示或提交凭据、真实主机路径或现场设备标识。

“通过”是静态 schema、字段关系和派生规则的证据；“失败”是该记录未通过这些规则的证据。它们都不是设备身份、通信、读回、启动采用、安装方向、运行条件或全局安全的证据。把这些边界写入最终报告，并把任何需要设备或现场验证的结论列为未决项。
