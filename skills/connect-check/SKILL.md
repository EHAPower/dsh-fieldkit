# 连接检查

用于确认一次只读 USB 检查能否取得明确设备的身份与状态证据。只可使用 `fieldkit_devices` 和 `fieldkit_diagnose_usb`；不要读取任何源代码仓库，也不要请求或执行运动、停止、复位、保存、清错或维护。

1. 在 Harness 图形界面中运行 `fieldkit_devices`，向操作者显示 USB 候选。
2. 要求操作者在界面中明确选择一个完整序列号。没有明确选择时停止并报告“未选择设备”；绝不按排序、索引或“第一台”自动选择。
3. 用该序列号调用 `fieldkit_diagnose_usb({ serial })`。它按固定顺序收集只读快照并保存 Markdown 与 JSON 证据。
4. 报告应分别列出：所选目标、身份 UID、`run_nonce`、每一类快照的结果、保存的证据路径和任何缺失/错误。只有同一 UID 且 `run_nonce` 一致的快照可关联为同一运行实例。

把工具返回的原始事实称为“证据”；把对连接可用性或后续排查的解释称为“判断”。不要把候选枚举、一次回复或离散快照描述为持续连接、原子状态、设备采用、机构动作或全局安全。检查有效仅说明本次所需的只读证据已取得；检查不完整仅说明证据不足，两者都不代表现场整体安全。
