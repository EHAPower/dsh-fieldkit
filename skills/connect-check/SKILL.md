# 连接检查

用于解释用户已选择目标的官方连接检查结果。工作台未选择目标时，引导用户在目标列表中选择；不要猜测、枚举替代目标或自行构造设备参数。

1. 用户要求只看当前选择时，只调用 `fieldkit_context()`；它只提供当前目标、内存 `lastResult` 和静态命令目录。没有当前目标就报告不可用，不补发读取。
2. 用户请求连接检查时，调用当前工作台公开的 `fieldkit_command(...)`，使用一个用户指定的官方只读命令。不要在它之前追加身份、状态或其他命令。
3. 原样报告官方 HTTP 返回的状态、`bodyText`、错误、unknown 和报告路径。unknown 只说明这次检查的返回状态，不限制之后的工作台命令。

区分“官方结果”和“对结果的解释”。token、主机路径和未显示的服务数据不得进入回复。
